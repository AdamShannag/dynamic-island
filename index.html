Dynamic Island

APT repository for Dynamic Island (Ubuntu, GNOME Shell 46+, amd64 and arm64).

curl -fsSL https://adamshannag.github.io/dynamic-island/setup.sh | sudo sh
sudo apt install dynamic-island
island setup

Or add it by hand:

curl -fsSL https://adamshannag.github.io/dynamic-island/dynamic-island.gpg | sudo tee /usr/share/keyrings/dynamic-island.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/dynamic-island.gpg] https://adamshannag.github.io/dynamic-island stable main" | sudo tee /etc/apt/sources.list.d/dynamic-island.list
sudo apt update && sudo apt install dynamic-island
